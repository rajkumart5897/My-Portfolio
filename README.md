# My Portfolio

A personal portfolio website for **Rajkumar**, a B.E. Computer Science Engineering student and full-stack developer. The site is a static, multi-page HTML/CSS/JS build — no framework or build step required — covering a home page, education & skills, projects, internships, about, and contact pages, with a light/dark theme toggle.

🔗 Live structure: `src/home.html` is the entry point; all pages link to one another through a shared nav bar.

## Quick start

```bash
cd src
python3 -m http.server 8000
```

Then visit `http://localhost:8000/home.html`. See [docs/getting-started.md](docs/getting-started.md) for other ways to run and deploy the site.
