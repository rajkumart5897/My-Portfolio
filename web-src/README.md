# web-src

The original static HTML/CSS/JS portfolio site, kept for reference while it's rebuilt as a native GTK4 app in [`linux-src/`](../linux-src/).

It still works standalone — see [`docs/getting-started.md`](../docs/getting-started.md) for how to serve it locally — but it's no longer where active development happens, and it isn't part of the GTK app's build. See [`docs/site-structure.md`](../docs/site-structure.md) for where this fits in the repo overall.
