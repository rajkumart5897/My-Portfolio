Hardware-Compat

Hardware compatibility checker and driver advisor for Linux.

PythonLinuxHTMLCSS
GitHub Documentation

Overview

Hardware-Compat is a Linux hardware compatibility checker that scans PCI and USB devices, detects driver issues, firmware updates, SMART disk health, battery condition, and BIOS information before recommending exact commands to resolve problems.

Built entirely with the Python standard library and standard Linux utilities, the project requires no third-party Python packages.

Features

  • Automatic PCI and USB hardware detection
  • Driver status analysis
  • Wi-Fi and Bluetooth rfkill detection
  • Firmware update detection
  • SMART disk health monitoring
  • Battery health reporting
  • BIOS version detection
  • Interactive driver recommendations
  • Built-in web dashboard
  • JSON export support
  • Distro-aware installation support
