# Customization

- **Colors & theme tokens** — edit the CSS variables at the top of `src/styles.css` (`:root` and `:root[data-theme="dark"]`). See [theming.md](theming.md) for how the toggle works.
- **Navigation links** — the nav bar is duplicated at the top of each HTML file; update all pages together when adding or renaming a page.
- **Contact details** — `src/contacts.html` has placeholder links for LinkedIn and email (marked with HTML comments) that should be filled in with real URLs.
- **Resume** — the "Download resume" button on `home.html` links to `Rajkumar_resume.pdf`, which should be placed alongside the HTML files.
